# Mushrooms

**Mushrooms** is a small online multiplayer game prototype made in **Unity** and **C#**.

Players compete against each other to collect as many mushrooms as possible. The match turns a simple collection mechanic into a short race for the highest score, with the final results displayed on a leaderboard.

## Gameplay

The core loop is simple:

1. Join the game with other players.
2. Explore the level and collect mushrooms.
3. Compete for the highest score before the match ends.
4. Compare the results on the leaderboard.

The project was created as a prototype focused on testing a compact multiplayer gameplay loop rather than building a full-scale game.

## Features

- Online multiplayer gameplay
- Competitive mushroom collecting
- Player movement and interaction
- Score tracking
- End-of-match leaderboard
- Simple UI for gameplay feedback and results

## Running the Project

1. Clone the repository:

```bash
git clone https://github.com/sensecreep/Mushrooms.git
```

2. Open the project through **Unity Hub**.
3. Use **Unity 6000.2.7f2**.
4. Let Unity restore the required packages.
5. Open the main scene and run the project.
